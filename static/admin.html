Server-Verwaltung

Spiele verwalten

Die Daten bleiben in einer gemeinsamen SQLite-Datenbank. Installationen und Löschungen erfordern einen separaten Administrator-Token.

Nur eigene, vertrauenswürdige Frontend-ZIPs installieren: Enthaltenes JavaScript wird unter deiner Serveradresse ausgeführt. Im Heimnetz ist HTTP für normale Seiten möglich; API-/Admin-Tokens sind über HTTP jedoch nicht verschlüsselt. Für den produktiven iPhone-Betrieb empfehlen wir lokales HTTPS.

Administratorzugang

Nicht angemeldet. Der Token wird nur im Arbeitsspeicher dieser Seite gehalten.

Installierte und gespeicherte Spiele

Mit Administrator-Token verbinden.

Spiel-ZIP installieren oder aktualisieren

Es werden nur statische Dateien unter /apps/spiel-id/ abgelegt. Kein Python- oder Node-Code aus dem ZIP wird ausgeführt. Vor jedem Update wird ein SQLite-Backup erstellt. Der Browser muss bei Yatzy und Flip 7 weiterhin einmalig den Spiele-API-Token erhalten.

SQLite-Sicherungen

Vor Datenlöschungen wird eine vollständige SQLite-Kopie erstellt. Lade regelmässig eine Kopie ausserhalb des Ubuntu-Servers herunter.
